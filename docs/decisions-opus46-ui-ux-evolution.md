## 一、UI / UX 审美与材质演进（Liquid Glass 与灵动岛高阶层次）

### 1. 材质与对比度核心原则：自适应双层基底（Adaptive Scrim）
在上一阶段的修复中，我们彻底根除了“玻璃套玻璃（Glass-in-Glass）”导致的白色白雾化问题，确立了“外壳单层玻璃 + 纯色填充（fill token）”的基本范式。为了在 macOS 多彩、浅色动态壁纸及纯黑全屏应用间无缝切换，Opus 4.6 提出以下高阶规范：

1. **三档色调的视觉语义对齐**：
   - **最玻璃（Clear / 0.15~0.25）**：突出物理透光感与周围色彩折射。
     - *底色衬底*：`Color.black.opacity(0.18)`，保证在纯白壁纸下对比度达到 4.5:1。
     - *描边高光*：`Color.white.opacity(0.14)` 1px 细线，呈现水晶边缘倒角的高级折射感。
   - **默认平衡档（Regular / 0.45~0.55）**：日常工作与全屏同看推荐状态。
     - *底色衬底*：`Color.black.opacity(0.42)`。
     - *色彩模式*：强制锁定 `.dark`，文字统一采用苹果单色分级（Primary 96% 白 / Secondary 72% 白 / Tertiary 48% 白）。
   - **毛玻璃色调（Tinted Dark / 0.75~0.90）**：高对比、抗反光与防干扰模式。
     - *底色衬底*：`Color.black.opacity(0.78)`，接近哑光黑曜石质感。
     - *高光描边*：移除顶部高光，消除任何对内容阅读的视线干扰。

2. **双段式环境景深物理阴影（Dual-phase Ambient Shadow）**：
   摒弃单层粗糙投影，在展开态采用双层物理阻尼投影：
   ```swift
   // 紧贴卡片的接触阴影（Contact shadow）
   .shadow(color: Color.black.opacity(0.18), radius: 5, x: 0, y: 2)
   // 营造大空间漂浮感的漫反射阴影（Ambient shadow）
   .shadow(color: Color.black.opacity(spec.isGlass ? 0.28 : 0.48), radius: 24, x: 0, y: 12)
   ```

3. **灵动岛硬件融合（Seamless Hardware Knot）**：
   - 在 MacBook 刘海屏上，收缩态必须维持绝对纯黑（`#000000`），HUD 顶边缘与屏幕物理顶边重合，禁用任何顶部边框与高光，杜绝任何视觉接缝。
   - 仅在伴随同看或分析时，从刘海两侧水平向外伸出平滑圆角“耳朵”，使用 `.symbolEffect(.pulse)` 呈现白色微光呼吸，绝不使用艳丽的蓝绿色（Cyan）。

## 二、文案体系演进（UX Copywriting）：彻底去 AI 味

### 1. 文案原则：动词主导、陈述事实、克制专业
- **禁止 AI 口号与套话**：严禁出现“智能知识管家”、“AI 为您提炼”、“开启智慧学习之旅”等大词空词。
- **直击操作本质**：每个按钮必须是一个明确的及物动词（如：`抓取当前帧`、`导出项目待办`、`在 Obsidian 中查看`）。
- **强化状态因果**：状态不仅说“在做什么”，更说“在学什么”（如：`同看中 · Blender 4.2 几何节点`）。

### 2. 系统关键文案升级对照表

| 场景 | 原先/常见文案 | Opus 4.6 推荐文案 | 设计考量与心智模型 |
|---|---|---|---|
| **状态栏显示** | `伴随同看(Bilibili)` | `学习中 · 哔哩哔哩` | 去掉冗余副词，强化沉浸式学习体验 |
| **聚焦学习目标** | `已配置聚焦关键词` | `聚焦 · Blender 建模 / 几何节点` | 突出具体专业领域，一目了然 |
| **未配置目标** | `点击配置聚焦目标` | `+ 设定学习方向与本地项目` | 引导用户建立“学习与项目”的链接 |
| **知识卡片核心结论** | `AI 总结结论` | `核心机理` | 强调底层逻辑与工作机制，非浮浅摘要 |
| **反哺按钮** | `反哺项目优化` | `导出到项目优化清单` | 及物动词，清晰告知动作发生的终点 |
| **复制按钮** | `复制精华` | `拷贝核心参数与结论` | 精确表述复制内容的价值密度 |
| **快捷键抓取提示** | `抓拍当前前台窗口 (⌘⇧S)` | `捕获当前画面 (⌘⇧S)` | 简练、有力，符合 macOS 标准菜单命名 |
| **删除与撤销** | `已删除卡片` | `已删除「...」（⌘Z 撤回）` | 即时反馈并附带快捷键提示，给用户掌控感 |

## 三、功能闭环演进：解决“学 Blender 无法反哺项目”的核心痛点

用户反馈的核心痛点在于：**“看 Blender 教程，总结只是文章提供了一些 Blender 技能，没有说能够整理资料反哺给回项目然后提供可优化的手段”**。

为了实现从**“被动看视频”**到**“直接改善本地生产力”**的质变，Opus 4.6 设计了**“三级反哺消化漏斗（Tri-Level Feedback Funnel）”**：

```
+-------------------------------------------------------------+
| 阶段 1：靶向工程锚定 (Project Anchor)                        |
| 用户在设置中绑定本地项目目录 (如 ~/Documents/MyGame3D)      |
| 系统自动提取项目技术栈与待解决瓶颈 (如: EEVEE 次表面散射发灰) |
+-------------------------------------------------------------+
                              ↓
+-------------------------------------------------------------+
| 阶段 2：费曼参数级深拆 (Feynman Deep Extraction)             |
| 1. 底层原理类比：为什么有效（物理原理 / 拓扑规律）         |
| 2. 实操参数配方：具体修改哪个属性、输入什么数值             |
| 3. 主动回忆问答：折叠自测卡，检验是否真懂                   |
+-------------------------------------------------------------+
                              ↓
+-------------------------------------------------------------+
| 阶段 3：直接生成工程待办 (Actionable Task Injector)         |
| 一键将提炼点转换为带文件与行号的 Markdown Task:             |
| "- [ ] 【Shader优化】将材质粗糙度降至 0.08 并开启清漆层..."  |
| 自动追加至本地项目的 TODO.md / learning-feedback.md         |
+-------------------------------------------------------------+
```

### 1. 结构化知识模型（Data Schema）强化点
在 `KnowledgeEntry` 中固化以下必填工程字段：
- `prerequisites`: 前置依赖（避免新手盲目尝试高级功能）。
- `conceptBreakdown`: 核心概念拆解（包含 `term`, `explanation`, `analogy`）。
- `projectOptimizations`: 专门针对用户项目给出的优化建议（明确说明**改哪里**、**怎么改**、**预期收益**）。
- `actionableSteps`: 实操步骤（包含具体菜单路径、节点名称、快捷键）。
- `selfCheckQA`: 2 道高质量主动回忆自测题，展开卡片后以折叠问答形式呈现。

### 2. 双向知识回流与反哺流
1. **项目待办注入（TODO Injection）**：
   在 `NotchKnowledgeCardView` 的右键菜单和卡片顶部增加快捷动作：
   - `注入为项目待办 (- [ ])`：直接将 `projectOptimizations` 格式化为标准 Markdown 任务列表，追加到指定项目根目录的 `TODO.md` 中。
2. **知识库结构化存储（Obsidian Console）**：
   保持单文件极简设计（`00-NotchMind控制台.md` 与分类文件 `02-AI学习与教程.md`），使得所有沉淀内容可直接无缝导入 Google NotebookLM 进行长文多模态播客生成与深度问答。

## 四、多屏与全屏交互人机工程

1. **全屏沉浸保障**：
   - 依赖已落地的 `HUDHostingView.acceptsFirstMouse`，确保在全屏播放器或浏览器中，首次点击直接响应按钮，无需先激活窗口。
   - 收起态完全透明处点击直接透传底层网页或视频播放器进度条，绝不发生误触拦截。
2. **外接显示器 4 档定位记忆**：
   - `topCenter`（顶部居中，对标原生刘海位置）
   - `topLeading`（左侧避让，适合居中放置菜单栏小组件的用户）
   - `topTrailingSafe`（右侧安全区，避开系统控制中心与时间插件）
   - `custom`（自由拖拽，支持跨分辨率屏幕比例记忆）
3. **全局快捷呼出与收起**：
   - 保持 `⌘⇧S` 作为全屏或任意应用下的瞬时画面抓取热键。
   - 建议在下一迭代增加 `⌘⌥Space` 快速展开/折叠 NotchMind HUD，无需频繁移动鼠标。
